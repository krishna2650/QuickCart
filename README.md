# 🛒 QuickCart

QuickCart is a full-stack grocery shopping web application where users can browse products, add items to their cart, change quantities, remove products, and view their cart total.

## ✨ Features

- 🛍️ Browse popular grocery products
- 🔍 Product search bar
- 📍 Delivery location display
- 🛒 Add products to cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove products from cart
- 💰 Automatic cart total calculation
- 📱 Mobile-friendly responsive layout
- 🗄️ MongoDB database integration
- ⚡ Node.js and Express backend

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- Mongoose
- CORS

### Database
- MongoDB

### Development Tools
- Visual Studio Code
- MongoDB Compass
- Git & GitHub
